# Deep Learning Laboratory Tutorials (2026)

This repository contains practical implementations across core deep learning topics, including Multi-Layer Perceptrons (MLP), Artificial Neural Networks (ANN), Stochastic Gradient Descent (SGD) and advanced optimization methods, data augmentation, Convolutional Neural Networks (CNN), YOLO object detection, Generative Adversarial Networks (GANs), and Recurrent Neural Networks (RNNs).

Each tutorial folder contains self-contained implementation code alongside a detailed Word report (`.docx`) documenting the model architecture, training curves, hyperparameter choices, and quantitative evaluation metrics.
